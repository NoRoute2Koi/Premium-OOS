## README

## Git
- Если рабочая директория не git репозиторий - инициализируй его
- Используй ветку main
- Не изменяй Global Config
- Создавай коммиты для различных изменений
- Придерживайся модели SemVer
- Веди .gitignore
- Тебе запрещенно пушить репозиторий

## NixOS
- Ты работаешь на NixOS, учитывыай это
- Для временных пакетов используй "nix-shell -p"
- Для пакетов, который могут пригодиться в дальнейшем для пользователя, используй постоянный shell.nix
