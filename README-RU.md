# Premium-OOS

[English](README.md) | Русский

Модуль KernelSU для разблокировки флагманских эффектов размытия, полупрозрачности и премиального интерфейса OriginOS 6 на устройствах iQOO и Vivo.

> [!WARNING]
> Начиная с версии `v0.8.0` (ветка `main`), патчер стал универсальным для всех устройств iQOO/Vivo. Все версии ниже `v0.8.0` предназначены только для **iQOO Z9**.

## Описание

На бюджетных и среднебюджетных устройствах, таких как iQOO Z9 (Snapdragon 7 Gen 3 / SM7550), визуальные эффекты OriginOS 6 урезаны на уровне таблиц конфигурации и проверок системного фреймворка:
- Размытие часов на экране блокировки и Always-On Display, виджетов и шейдеры деформации заблокированы режимом Space System (`ssMode`) в `ActivityTaskManagerService`. Если режим равен 0 (`?spacesystem`), компонент `VivoDreamClockApp` полностью отключает шейдеры блюра.
- Оконный менеджер переводит режим в `ssMode = 2` только в случае, если при старте `system_server` вызов `FtFeature.getFeatureAttribute("vivo.software.spacesystem", "version", "0") >= 2` возвращает истину.
- Вендорный HAL ConfigStore (`vendor.vivo.hardware.configstore@1.0-service`) требует обязательного наличия параметров `vivo-support = 1` и `is_support_zygote = 1` в `vivo_config.ini`. При отсутствии `vivo-support` HAL считает фичу неподдерживаемой и возвращает значение по умолчанию `0`.
- SystemUI оценивает производительность устройства в `SystemPropertiesFacade.getPerformanceLevel()`. Без флагов `vivo.software.nativeblur` и Space System v2+ устройство определяется как low-performance (уровень 40 вместо 30), что отключает анимации деформации окон.
- Размытие фона при открытии и закрытии приложений отключено (`support_blur=0` в конфигурации vendor, `ro.launcher.blur.appLaunch=0`).
- Профиль системных эффектов переведён в режим Lite (`system_effect_type=1` вместо `0`).

Модуль динамически подменяет конфигурацию в оперативной памяти через KernelSU overlayfs и инъекцию системных свойств без записи в физические разделы и без изменения хэшей AVB.

## Возможности

- Разблокировка шейдеров размытия часов на экране блокировки и AOD, а также виджетов.
- Включение размытия деформации фона при открытии и закрытии приложений в лаунчере.
- Активация пайплайна Space System v3 level 1 (режим `spacesystem` 2).
- Переключение профиля системных эффектов с Lite (`1`) на Full (`0`).
- Включение нативного аппаратного размытия, motion blur и полупрозрачности V-Glass.
- Универсальная поддержка устройств за счёт динамического патчинга стокового `/vendor/etc/vivo_config.ini` (`patch_config.sh`).
- Проверка заводской поддержки: предупреждает и запрашивает подтверждение кнопками громкости (`Громкость+` — продолжить, `Громкость-` — отменить) если премиальные эффекты уже поддерживаются с завода.
- Три профиля оптимизации (`High`, `Medium`, `Lite`), сохраняющие все флагманские эффекты при настройке радиуса блюра и GPU Boost.
- Оптимизация шейдера Dual Kawase (`debug.hwui.vivo_blur_dualKawase=true`) и аппаратное кэширование слоёв шторки для устранения лагов.
- Безопасность при временном руте (temproot) без записи в физические разделы.
- Надежный инсталлятор с мгновенной синхронизацией live update и защитой от повторного монтирования.
- Полная совместимость с метамодулями, включая Hybrid Mount.
- Поддержка кнопки Action в менеджере для мягкой перезагрузки и перезапуска ConfigStore HAL.
- Корректное размонтирование при удалении модуля через `uninstall.sh` без блокировок ресурсов (`EBUSY`).
- Сохранение настроек пользователя в приложении «Настройки» («Премиальные текстуры» и «Размытие в реальном времени»): модуль открывает системные возможности, не перезаписывая принудительно пользовательские тумблеры при перезагрузках.
- Набор оптимизаций рендеринга под процессор Snapdragon 7 Gen 3 (Adreno 720) и 1.5K дисплей.

## Оптимизация производительности для iQOO Z9

Для предотвращения микрофризов и просадок FPS на видеоядре Adreno 720:
- **Сбалансированный радиус деформации**: Радиус размытия окон снижен с 44 до 24 (`min_blur_radius_temp = 24`), что вдвое уменьшает нагрузку на выборку текстур GPU при сохранении мягкого визуального эффекта.
- **Динамическая частота кадров блюра**: Включен параметр `debug.blur.dynamic.frameRate=true`. Это позволяет графическому движку обновлять текстуру размытия с частотой 60-90 fps, сохраняя движение окон плавным на 120/144 fps.
- **Отключение избыточного градиента**: Отключены тяжелые проходы градиента 4-го уровня (`persist.debug.blurlevel_4=false`), создававшие узкое горлышко по пропускной способности памяти на высоком разрешении.
- **Аппаратная оптимизация центра управления**: Включен параметр `persist.debug.qs_enable_hardware_optimize=true`.
- **Повышение частоты GPU**: Задан порог минимальной частоты Adreno при входе в анимации размытия (`persist.blur.GPU.minlevel=60`, длительность 600 мс).

## Архитектура модуля

1. `system/vendor/etc/vivo_config.ini`:
   - Настраивает блоки `[vivo.software.spacesystem]`, `[vivo.software.spacesystem.borderlight]`, `[vivo.software.nativeblur]`, `[vivo.software.motionblur]`, `[vivo.software.asyncanimboost]`, `[vivo.software.vglasseffect]`, `[vivo.software.realtimeblur]` и оптимизированный `[vivo.software.windowdeformblur]`.
   - Задаёт флаги `vivo-support = 1` и `is_support_zygote = 1` для корректного экспорта параметров демоном ConfigStore HAL в Zygote и System Server.
   - Использует каноническую структуру `system/vendor`, совместимую с символическими ссылками system-as-root и `metainstall.sh` в Hybrid Mount, исключая дублирование каталогов vendor.
2. `system.prop`:
   - Задаёт системные свойства `ro.vendor.vivo.software.*` на ранней стадии инициализации Android.
   - Задаёт параметры оптимизации для графического ускорителя Adreno 720.
3. `customize.sh`:
   - Устанавливает корректные права на исполняемые файлы и директории.
   - При установке через KernelSU Manager (`modules_update`) мгновенно синхронизирует файлы модуля в активную директорию модулей, обеспечивая видимость модуля без необходимости аппаратной перезагрузки.
4. `post-fs-data.sh`:
   - Назначает SELinux-контекст `u:object_r:vendor_configs_file:s0` для конфигурационных файлов.
   - Задаёт параметры через `resetprop`.
   - Не выполняет преждевременный bind-mount во избежание конфликта с проверкой владения оверлеем в метамодулях.
5. `service.sh`:
   - Обеспечивает резервный bind-mount после завершения загрузки системы только в случае, если оверлей менеджера не активен.
6. `action.sh`:
   - Вызывается по нажатию кнопки Action в KernelSU / SukiSU Manager.
   - Проверяет монтирование, перезапускает `vendor.vivo.hardware.configstore@1.0-service` и выполняет мягкую перезагрузку Zygote.
7. `uninstall.sh`:
   - Вызывается при удалении модуля в менеджере.
   - Динамически размонтирует все смонтированные слои модуля и удаляет внедрённые параметры для чистого возврата к стоковому состоянию.

## Безопасность

- Не изменяет физические разделы устройства (`/system`, `/vendor`, `/product`).
- Полностью совместим с временным рутом (temproot) и верификацией AVB.
- Все изменения применяются исключительно через overlayfs в памяти и через `resetprop`.

## Требования

- iQOO Z9 под управлением OriginOS 6 (Android 16 / платформа SM7550).
- KernelSU / APatch / Magisk с поддержкой overlay.
- Среда сборки на NixOS (через `nix-shell`).

## Сборка

Для сборки архива модуля:

```bash
./build.sh
```

Готовый архив сохраняется в каталог `out/premium-oos-v<VERSION>.zip`.

## Установка и активация

1. Перенесите `out/premium-oos-v0.8.0.zip` на устройство.
2. Прошейте zip через KernelSU Manager (или APatch / Magisk).
3. Активация:
   - При стандартном постоянном root: выполните перезагрузку устройства.
   - При временном root (temproot): нажмите кнопку «Действие» (Action) рядом с модулем в менеджере KernelSU / SukiSU или выполните вручную:
     ```bash
     su -c "killall -9 vendor.vivo.hardware.configstore@1.0-service && setprop ctl.restart zygote"
     ```
4. Проверка активации через adb shell:
   ```bash
   su -c "dumpsys window | grep spacesystem"
   ```
   В строке глобальной конфигурации должно отображаться `spacesystem` вместо `?spacesystem`.
5. Дайте смартфону время для оптимизации (поставьте его на зарядку на ночь и не трогайте его).
